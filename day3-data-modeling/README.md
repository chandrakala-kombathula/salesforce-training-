# Salesforce Summer Program - Day 3

## App vs Object vs Record vs Field

### App
Collection of related functionalities.

### Object
Database table in Salesforce.

### Record
Single row of data in an object.

### Field
Single piece of information in a record.

## Standard vs Custom Objects

### Standard Objects
Already provided by Salesforce.

### Custom Objects
Created by users based on business needs.

## College Management System
